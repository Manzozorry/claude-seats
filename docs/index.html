What it does

Built to sit next to your work, out of the way.

A native menu on the Mac, a themed bar widget on Omarchy, and the same small CLI underneath both.

macOS · menu bar

A real menu, not a web view

Every saved account, its plan, session and weekly usage, and a refresh, all in the menu macOS already draws for you. Logins live in the Keychain, next to Claude Code's own.

Switch

One click, no /logout

Each saved login gets a button. Pick one and every new claude session uses it. Middle-click the bar icon to flip to the next.

Alerts

A nudge before you hit the wall

When the active account crosses 90% and another one has room in the same window, you get a notification. Click it to switch.

Bar widget

              
Matches the built-in Agents panel and follows your theme.

              
$ omarchy plugin add https://github.com/Manzozorry/claude-seats --enable

              
# optional: sit right next to Agents
$ omarchy bar move zorry.seats --before omarchy.agents

            

            

              
Menu bar, through SwiftBar

              
macOS 12 or newer. The installer gets SwiftBar through Homebrew if you don't have it.

              
$ git clone https://github.com/Manzozorry/claude-seats.git
$ cd claude-seats && ./macos/install.sh

            

            

              
CLI on any distribution

              
Just the seats command. Python 3 and Claude Code are all it needs. Bind seats toggle to a key for one-key switching.

              
$ git clone https://github.com/Manzozorry/claude-seats.git
$ install -m 0755 claude-seats/seats ~/.local/bin/seats

        How it works
        
A copy of each login, kept fresh.

        
Claude Code keeps its login in one place. Seats keeps a copy per account and swaps them carefully.

      

      

        

          1
          
Save the live login back

          
Refresh tokens rotate. Before switching, the active account's current login is written back to its own copy so it never goes stale.

        

        

          2
          
Install the target

          
The chosen account's tokens go where Claude Code looks: ~/.claude/.credentials.json on Linux, the Keychain on macOS, plus its oauthAccount details.

        

        

          3
          
Refresh the numbers

          
Limits come from the same endpoint as Omarchy's Agents widget, parsed by Omarchy's own collector, so the numbers match.

        

      

      

        
        
Idle accounts are left alone. Seats never refreshes a login that isn't active, because that would rotate its token without Claude Code knowing. When an idle login lapses you see its last known numbers instead.

      

    

  


  
  

    

      

        
Running sessions keep their account
A session that's already open stays on the account it started with. Switch between sessions when you can.

        
Don't use /logout
It can revoke the saved login. To change account, switch in Seats or just log in again.

        
macOS reports welcome
The Mac version is tested against a simulated Keychain, not yet on a real Mac. Open an issue if something's off.
